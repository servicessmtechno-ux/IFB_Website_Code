IFB Washing Machine Error Codes

IFB washing machines show an error code on the display when the machine detects a fault. The meaning of a code can vary depending on the model, so treat any code as a starting point for diagnosis.

What a code may mean: for example, a drainage-related code such as P10 usually points to a blocked drain filter or drain hose, while codes like E2, E3 or F5 often relate to water filling or draining issues.
Safe basic checks: you can safely check the drain filter, the water supply tap and that the door is fully closed. Do not open or touch internal electrical parts.
When professional diagnosis is needed: if the code keeps returning after basic checks, the machine may have a sensor, PCB or motor fault that needs professional attention.
